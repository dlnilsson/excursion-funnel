Configure your agent

Route Claude Code or Codex through excursion funnel to include its usage in this dashboard.

Add this to your Claude Code settings.json:

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:8787"
  }
}

Create ~/.codex/excursion-funnel.config.toml with:

model_provider = "excursion-funnel"

[model_providers."excursion-funnel"]
name = "Excursion Funnel Proxy"
base_url = "http://127.0.0.1:8787/v1"
wire_api = "responses"
requires_openai_auth = true
